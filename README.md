# my-first-site

A personal website I built while learning web development.

**Live site:** https://markies-vanec.github.io/my-first-site/

## What it includes

- A responsive layout that works on phones (HTML, CSS, flexbox)
- A click counter with a reset button
- A to-do list that saves tasks in the browser (JavaScript, localStorage)

## What I learned

- Using Git and GitHub to save and publish my work
- Structuring a page with HTML and styling it with CSS
- Making pages interactive with JavaScript
